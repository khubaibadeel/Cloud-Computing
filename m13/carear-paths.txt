

# Carear  Paths After AWS Foundation:
    U must have Basic to Intermediate Understanding of Cloud Computing to comply with these jobs.

    1. Cloud Support/Help Desk
    2. Junior/Senior Cloud Engineer --> in which u have a proper cloud provider and keep the applications of your company live using different cloud providers.
    3. Cloud Administrator/SysOps --> U create a Cloud Environment and Provide help to ur customers.
    4. Associate Solutions Architect --> Very Advance Level Job --> After 7-10 yrs of experience --> Includes How to design an architecture on Cloud and how it adapts in coming days.
    5. DevOps/Platform Engineer --> Automates application deployment, infrastructure setup, monitoring, and software delivery. Makes development and deployment faster, more reliable, and repeatable.
    6. Cloud Security Analyst --> Protects cloud infrastructure, applications, users, and data from security threats. 

# Freelancing Services u can sell beside the job:
    Start with small fixed-scope services, then Grow into Monthly Support.

    # Starter Gigs:
        1. AWS Account Setup, MFA, Billing Alarms
        2. EC2 Webs Servers Deployment and SSL Handovers
        3. S3 Static Website hosting and CloudFront setup
        4. Creating EBS Snapshots, Backup Schedule, and Doing Restore Tests
        5. Cost Cleanup: Unused EIPs, Volumes, and Snapshots

    # High-Value Retainers:
        1. Monthly AWS Health Checks and Security Review
        2. Design a VPC (Virtual Private Cloud) for small production apps
        3. Monitoring, Logs, Alerts and Incident Runbooks
        4. Migration from Shared Hosting to AWS (Physical/Other Servers to AWS Servers)
        5. Documentation and training for client teams (Document what you created and train their staff to operate it)


    To Target all of these things, You Must have your own Portfolio Projects.

    # Some Portfolio Projects which can prove that u can Do the Work:
        A good portfolio shows Screenshots, Architecture, Commands, Costs, and Lessons learned.

        1. Secure AWS Account Setup (MFA, IAM Admin user, Billing Alarm, Budget, Cleanup Checklist)
        2. S3 Static Website (HTML, CSS site, Bucket Policy, CloudFront, and Custom Domain notes)
        3. 3-tier VPC Design (Public/Private subnets, NAT, Route Tables, Security Groups)
        4. EC2 + EBS snapshots and operations (Attatch volume, resize, snapshot, restore, encryption)
        5. Monitoring and Cost Review (CloudWatch Alarm, Logs, Budget report, Remediation plan)

        # Portfolio Rules:
            "Every Portfolio Project shouls include a Problem, Architecture Diagrams, Step-by-Step Build, Evidence screenshots, Cost notes, and Cleanup Steps."


    # Skills to Add Around AWS:
        AWS is the Platform; These Supporting Skills make u Employable and Billable:

        1. Linux (SSH, Services, Logs, Package Managers, Shell Basics)  --> Linux is excessively used in EC2 and S3. 
        2. Networking (CIDR, DNS, HTTP./HTTPS, Routing, Firewalls) --> Must have Networking basics' understanding for VPC.
        3. Security (IAM, MFA, Best Practices, Least Privilege, Encryption,Logging) --> Must have Security basics' understanding for VPC.
        4. Automations (Bash or Python, AWS cli, Simple Scripts) --> Should know how to create simple automations using Bash or Python.
        5. Infrastructure as Code (Terraform or CloudFormation for repeatable builds) --> Should know how to create an Infrastructure by Coding, without going to the console using Terraform and CloudFormation.
        6. Operations (CloudWatch, Backups, Runbooks, Cost Controls) --> Should know how to deal with Logging, Error Finding, Debugging, and Incident Management.

        # Tip: 
            --> Cloud Carears Reward people who can Explain, Document, and Troubleshoot, not just click buttons in the Console.
            
        "AWS + Linux + Networking + Automations = Job-Ready Foundation."
