# Cloud Computing

This repository documents my learning journey in **Cloud Computing** through the DigiSkills course, with a focus on Amazon Web Services (AWS).

## Purpose

The purpose of this repository is to keep course notes, hands-on exercises, solutions, and learning resources in one place. It serves as a personal reference while I build practical cloud-computing skills and prepare for AWS-related roles.

## Contents

- Course modules and notes
- AWS cloud-computing concepts
- Hands-on exercises and solution files
- Career-path notes for AWS cloud computing
- Supporting learning material and documents

## Topics Covered

- Cloud-computing fundamentals
- AWS services and architecture basics
- Cloud deployment and operations
- Security, networking, storage, and compute concepts
- Career opportunities after building AWS cloud foundations

## Goal

To develop a strong foundation in cloud computing and AWS, create practical projects, and progress toward roles such as Cloud Support Associate, Junior Cloud Engineer, Cloud Administrator, or Junior DevOps Engineer.

## Note

This repository is intended for learning and practice. Content is added as I progress through the course and complete exercises.
