
# EC2 Instance Types and Selection Part I:
    EC2 Instance Types are named using Family, Generation, and Size.

    # Instance Type Naming Format:
        [family][generation].[size]

        Example --> t3.micro
        1. t --> T Family.
        2. 3 --> 3rd Generation.
        3. micro --> Micro Size.

    # Size Progression (Small --> Large):
        nano < micro < small < medium < large < xlarge < 2xlarge ...


    # General Purpose Instances (M, T Families):
        "Balanced: Compute, Memory, Networking."

        # M Family:
            - Steady, balanced workloads.
            - Predictable performance for demanding workloads.

        # T Family:
            - Burstable performance for variable workloads.
            - Includes Free Tier t2.micro.

        # Best For:
            1. Web Applications
            2. Dev/Test Environments
            3. Content Management Systems

        General Purpose instances are ideal when you need a balance of CPU, Memory, and Networking.


    # Compute Optimized Instances (C Family):
        "High CPU performance relative to Memory."

        # Best For:
            1. Batch Processing
            2. Gaming Servers
            3. Media Transcoding
            4. Simulations

        # Indicator:
            - Your application's CPU is consistently near 100% under normal load.


    # Memory Optimized Instances (R, X Families):
        "Very high RAM relative to CPU."

        # Best For:
            1. Large Relational Databases
            2. Redis / Memcached
            3. Big Data Workloads
            4. Real-time Analytics

        # Indicator:
            - Your application constantly runs out of memory.


    # Quick Comparison:
        1. General Purpose (M, T Families)
            - Key Strength --> Balanced Compute, Memory, and Networking.
            - Best For --> Web Apps, Dev/Test, Content Management, Small to Medium Apps.

        2. Compute Optimized (C Family)
            - Key Strength --> CPU; High CPU performance relative to Memory.
            - Best For --> Batch Processing, Gaming Servers, Media Transcoding, Simulations.

        3. Memory Optimized (R, X Families)
            - Key Strength --> RAM; Very high Memory relative to CPU.
            - Best For --> Large Databases, Caching (Redis/Memcached), Big Data, Real-time Analytics.


    # Lecture Summary:
        "We discussed the most basic and most used EC2 Instances for balanced workloads, compute-optimised, and memory-optimised."
